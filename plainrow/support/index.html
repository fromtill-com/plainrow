Start a ticket

Email till@fromtill.com. We reply from that address. Send column names and row count, never file contents.

Do files leave my machine?

No. Files never leave the machine. There is no upload, no account, and no telemetry. We never ask you to send a CSV for support. Describe column names and row count, not contents.

What can Lite do?

Open two CSV or TSV files, stack them, remove duplicate rows, and export. Files never leave this computer. Lite is a smaller tool: two files, stack, dedupe, export.

More than two files?

Lite holds two files on the counter. Stack those two, export, then open the result with another file if you need a second pass.

File too big?

If the browser complains, split the export or filter in the source tool first, then stack. Lite stays two files, stack and dedupe only.

What if something breaks?

Try a current desktop Chrome, Edge, Firefox, or Safari. Then email till@fromtill.com with column names and row count, not contents.

Refunds?

There is no paid product on this site. Lite is free in the browser. There is nothing to refund.

Will you take my files?

No. We never ask you to send a CSV. If something breaks, describe the shape of the file (column names, row count), not the contents.
