How this works

Open up to two CSV/TSV files, stack them, dedupe, export. Files never leave this computer.

  1. Open CSV or TSV files with the picker, drag-and-drop, or a synthetic demo. Lite holds two files on the counter.
  2. Stack unions columns and appends rows. Dedupe keeps the first or last row for each key.
  3. Export writes a comma-separated file to this computer. A UTF-8 BOM is optional for Excel.

Plainrow Lite is one HTML file. You do not install anything and you do not need a network after the file is on disk. There is no telemetry.

If something breaks, open Plainrow support. Email till@fromtill.com. Send column names and row count, never file contents.
